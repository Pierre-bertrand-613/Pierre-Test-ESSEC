# OOP & Design Patterns - my exercises

My exercises for the OOP & Design Patterns in Python course (AIDAMS, ESSEC). Course website: https://courses.dallard.tech/

| Folder | What's inside | Slide |
|---|---|---|
| [`01-git`](01-git) | Git mini exo + install script | 26 |
| [`02-bash`](02-bash) | Bash exercise (`env_install.sh`) | 18 |
| [`03-oop`](03-oop) | Operator overloading + inheritance | 67 |
| [`04-uml`](04-uml) | UML: hospital system + ABCD Records | 68 |
| [`05-design-patterns`](05-design-patterns) | Factory, Builder, Singleton, Adapter, Decorator, Strategy, Template Method | 70-87 |
| [`06-testing`](06-testing) | Testing with mocks (Groq API + FastAPI) | 93 |

To run the tests:

```bash
pip install -r requirements.txt
python3 -m pytest
```

I used one branch per exercise and merged each one into main when it was done (you can see it with `git log --graph`).
